# 과제 2-3 — 가상선 IN/OUT 카운트 + MQTT (2026-10-29 17:41, team4)

구성: IP 카메라 stream1 (2560x1440 25fps, camlib 최신 1장 리더) → YOLO11n TensorRT FP16 (imgsz 640, 사람만, conf 0.3) → Ultralytics ByteTrack (persist) → 발 위치(박스 아래 가운데)가 가상선의 어느 쪽인지 외적 부호로 판단 → 선에서 화면 높이 2% 이상 넘어가야 쪽 변경 인정(흔들림 방지), 같은 ID는 같은 방향을 연달아 세지 않음 → MQTT 127.0.0.1:1883 토픽 jiwon934/t2/line 에 {ts,id,dir,in,out} 발행(qos 1) + runs/t2_line.csv. 화면 :8030 (선·박스·ID·IN/OUT 표시), /reset으로 0 초기화. 스크립트 t2/line_count.py.
선: 정규화 (0.30,0.80)–(0.66,0.80) — 카메라 쪽 책상 줄과 가운데 줄 사이 통로 바닥, 카메라 앞 약 2–3 m. IN = 통로 안쪽 → 카메라 쪽, OUT = 반대.
처리 속도: 약 24.7 fps (추론+추적 약 21 ms, 2560x1440 프레임을 640으로 줄여 처리).
